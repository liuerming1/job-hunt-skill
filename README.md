# Job-Hunt Skill

BOSS 直聘求职全流程 skill（Anthropic Agent Skills 规范）。丢一份简历进来：AI 反推 3 个岗位方向 → 确认目标城市 → 自动拉起浏览器扫码登录 → 抓取职位并打分 → 候选列表里选 1 个 → 产出针对该岗位的定制简历与打招呼用语（结构化 Markdown，可直接交给 Word/PDF 类 skill 排版）。

另含三个单点快速入口：单岗位 JD 评估 / 单点简历修改 / 面试准备。

## 目录结构

```
SKILL.md            # 入口：意图路由 + 全流程编排 + 硬约束 + MD 输出契约
references/         # 8 份方法论 spec（打分、简历改造、打招呼语、抓取契约等）
scripts/            # 4 个纯 Python 标准库脚本，零第三方依赖
assets/             # 简历模板、候选人档案模板、config 示例
```

## 安装使用

把整个文件夹放进你的 agent 的 skills 目录（如 WorkBuddy / Claude Code 的 skills 路径），对话里说「帮我找工作 / 投简历 / 改简历」即可触发。

运行时 skill 会在工作目录旁创建 `job-hunt/` 作为**数据层**（个人档案、config、抓取缓存、生成的简历、浏览器登录态 profile）。**数据层属于个人隐私，不属于本仓库**——不要把它提交到任何公开仓库。

## 技术要点（实测踩坑记录）

- BOSS 搜索页数字用 PUA 私有区字符（U+E031-E03A）+ 自定义字体 `kanzhun-mix` 渲染反爬，脚本用页面内 canvas 像素比对破解，实测映射干净
- CDP 消息**不是** JSON-RPC——带 `jsonrpc` 键的请求会被 Chrome 静默丢弃
- 系统代理会截流 `127.0.0.1` 的 DevTools 请求，脚本强制 `ProxyHandler({})` 直连
- BOSS 本地职位供给不足时，带 city 参数的搜索仍会混入外地相似职位，列表页必须做城市预筛
- 遇 `code:37` 验证码立即停手切手动通道，不重试硬刚

## 合规边界

- 只生成打招呼语，**不自动发送**任何消息
- 低频抓取（请求间 3-8 秒随机间隔，每方向 ≤10 条）
- 抓取的 JD 数据只存本地，不回传任何服务器
- 简历与联系方式永不落对话上屏、永不进公开仓库
