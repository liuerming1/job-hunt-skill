# 07 — 中文写作风格（套话黑名单 + backtrack test）

> 写任何面向 HR 的文字之前必读：改简历、打招呼语、面试口径全部适用。逻辑来自原仓库 `03-writing-style.md`，英文套话黑名单换成中文套话黑名单。

## backtrack test（最重要的一条）

对每一条改写/每一句文案，问：

> **面试官在面试里追问这一条时，用户能不能不打磕巴地解释？**

- 能 → 保留
- 勉强 → 降级表述（「主导」→「参与」、「从 0 到 1」→「负责其中 X 模块」）
- 不能 → 删掉，退回原文

测试不通过还保留 = 用户在面试里被当场拆穿。这条规则的优先级高于「简历好看」。

## 中文套话黑名单

简历里禁止（出现即改写）：

- 「负责」开头的连续多条——改成动作动词（主导/搭建/推动/重构/落地）
- 「熟悉/了解/精通」三连——「精通」一律删，除非用户敢在面试里被考
- 「提升了效率」——没有数字的提升等于没说，标 XX 让用户补数据
- 「参与多个项目」「负责多项工作」——多项是多少？写数字
- 「具有良好的沟通能力和团队协作精神」——用事实替代：跨 X 团队推动 XX 落地
- 「富有激情，抗压能力强」——形容词堆砌，零信息量

打招呼语里禁止：

见 `05-opening-message.md` 的硬性禁止清单，两份清单同时生效。

## 数字化规则

- 每条经历尽量带结果数据：规模（DAU/GMV/预算）、变化（增长/降低百分比）、效率（周期缩短）
- 原简历没有的数字：**标 XX 让用户补，绝不编**。编一个数字，整份简历的可信度归零
- 数字的表述要能被追问：写「DAU 5 万→12 万」而不是「DAU 大幅增长」

## 语气

- 克制。动词比形容词有信息量，数字比动词有信息量
- 不堆砌、不抒情、不空喊。读起来像一份冷静的事实清单
- 一句话一个事实，复合句拆开
